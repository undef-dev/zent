# Zent

Zent создаётся с нуля как фреймворк машинного обучения на Rust. Разработка идёт от простой символьной модели и тензоров к нейронным сетям, их обучению и запуску.

Проект помогает разобраться, как устроены системы машинного обучения. Важно, чтобы по коду было понятно, как хранятся данные, сколько памяти требуют операции и какие вычисления за ними стоят.

## Цели

- **Понятное ядро:** тензоры, операции и автоматическое дифференцирование, в которых можно разобраться по коду и примерам
- **Компоненты для разных моделей:** общие операции и слои для языковых моделей, а в дальнейшем для работы с изображениями и других задач
- **Эксперименты:** подключаемые модули для проверки идей из исследований и выбора подходящего метода
- **Сравнение на своих данных:** проверки результатов, метрики качества, замеры скорости и памяти с сохранением настроек эксперимента

## Подход к разработке

Код делится на небольшие компоненты с понятными связями. Новые зависимости и абстракции добавляются, когда они нужны для конкретной задачи. Исследовательские модули и средства оценки будут подключаться отдельно от ядра. Биграммная модель уже выделена в самостоятельный пакет с примерами использования и тестами.

Сначала нужна понятная рабочая реализация. Затем можно сравнивать варианты и оптимизировать места, где измерения показывают лишние затраты времени или памяти.

## Состояние проекта

- `zent-bigram`: символьная биграммная модель с токенизацией, обучением на корпусе, воспроизводимой генерацией и запуском из командной строки
- `zent-tensor`: тензорное ядро в разработке; готовы форма, шаги, хранилище и конструкторы, следующий этап: индексирование

Проект на раннем этапе. Автоматическое дифференцирование, нейросетевые слои, трансформеры и общие средства обучения и оценки ещё предстоит написать.

## Варианты запуска

По мере развития проекта планируем три способа использовать модели:

- **Запуск в Rust:** подключение к приложению или запуск из командной строки, сначала на процессоре, затем с поддержкой видеокарт
- **Серверная часть и веб-интерфейс:** модель работает на своём компьютере или удалённом сервере, а интерфейс отправляет запросы через API и показывает результаты
- **WebAssembly:** модель работает прямо в браузере через API для JavaScript/TypeScript

Серверная часть с веб-интерфейсом и запуск через WASM пока в планах. Конкретные задачи и порядок разработки описаны в [ROADMAP.md](ROADMAP.md).

## Быстрый старт

Нужны Rust с поддержкой редакции 2024 и Cargo

```console
git clone https://github.com/undef-dev/zent.git
cd zent
cargo run -p zent-bigram -- --text "abba" --seed 42 --length 8
```

Для обучения на файле корпуса:

```console
cargo run -p zent-bigram -- --train data/corpus.txt --seed 42 --length 100
```

## Параметры запуска

- `--text <text>`: текст корпуса
- `--train <path>`: файл корпуса; имеет приоритет над `--text`
- `--seed <u64>`: начальное значение генератора случайных чисел, по умолчанию `0`
- `--length <usize>`: число генерируемых токенов, по умолчанию `0`
- `-h`, `--help`: справка
