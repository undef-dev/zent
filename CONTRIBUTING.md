# Участие в разработке Zent

В Issue опишите задачу или ошибку и приложите пример. Крупные изменения архитектуры, публичного API и новые зависимости лучше сначала обсудить.

## Подготовка изменений

- Один Pull Request — одна задача; посторонние правки вынесите отдельно.
- При изменении поведения добавьте или обновите подходящий тест.
- Пишите понятные имена и короткие комментарии. Документация и обсуждения могут быть на русском или английском.
- В PR объясните, что изменилось, зачем и как проверено. Отметьте изменения публичного API и форматов данных.

## Проверка

Из корня проекта:

```console
cargo fmt --all -- --check
cargo check --workspace --all-targets
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --all-targets
```

Укажите результаты и причины пропущенных или неуспешных проверок. Для изменений только в документации достаточно проверить текст и ссылки.
