# План развития проекта

## Текущая точка

Уровень 1: конструкторы 1.5 реализованы. Следующий этап — 1.6, индексирование.

## Уровень 0: статистическая биграммная модель с нуля

- 0.1: корпус и токенизатор
- 0.2: статистика биграммных переходов
- 0.3: вероятности и выборка из дискретного распределения
- 0.4: детерминированный генератор псевдослучайных чисел
- 0.5: `BigramModel` и генерация текста
- 0.6: CLI и тесты
- 0.7: завершение и отделение Level 0 в пакет `zent-bigram`

## Уровень 1: Tensor Core

- 1.0: Cargo workspace и отделение Level 0 — завершено
- 1.1: `Shape`, rank, dimensions и `numel`
- 1.2: strides и вычисление шагов по форме тензора
- 1.3: storage
- 1.4: первый `Tensor`
- 1.5: конструкторы `zeros`, `ones` и `from_vec` — реализованы
- 1.6: индексирование
- 1.7: reshape
- 1.8: поэлементные операции
- 1.9: broadcasting
- 1.10: reductions
- 1.11: matrix multiplication

## Дальнейшее развитие

- Уровень 2: Autograd
- Уровень 3: ядро нейронных сетей
- Уровень 4: Self-Attention
- Уровень 5: Transformer
- Уровень 6: Tiny GPT и языковая модель
- Уровень 7: данные, инфраструктура обучения, оценки моделей и бенчмарков

## Уровень 7: оценка моделей и бенчмарки

- 7.1: контрольные примеры и численные проверки Tensor, градиентов и моделей
- 7.2: загрузка пользовательских данных, разделение на обучение, валидацию и тест
- 7.3: метрики качества и сравнение базовых и исследовательских реализаций
- 7.4: измерение задержки и пропускной способности инференса, времени обучения и RAM/VRAM
- 7.5: фиксация конфигурации, seed, версий, устройства и условий измерений
- 7.6: сохранение отчётов и сравнение запусков

## Дополнительный этап: WebAssembly и JavaScript/TypeScript

После появления работающего инференса:

- W.1: собрать необходимые операции и простую модель для WebAssembly
- W.2: добавить отдельный пакет с JS/TS API для загрузки весов, входных данных и результатов
- W.3: проверить результаты относительно нативного запуска на Rust
- W.4: измерить размер сборки, время загрузки, задержку инференса и память
- W.5: подготовить браузерный пример и пакет для npm
