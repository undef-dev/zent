# План развития проекта

## Текущая точка

Уровень 1: индексирование 1.6 готово. Следующий шаг: 1.7, изменение формы тензора.

## Уровень 0: статистическая биграммная модель с нуля

- 0.1: корпус и токенизатор
- 0.2: статистика биграммных переходов
- 0.3: вероятности и выборка из дискретного распределения
- 0.4: детерминированный генератор псевдослучайных чисел
- 0.5: `BigramModel` и генерация текста
- 0.6: запуск из командной строки и тесты
- 0.7: завершение и выделение уровня 0 в пакет `zent-bigram`

## Уровень 1: тензорное ядро

- 1.0: общее рабочее пространство Cargo и выделение уровня 0 (готово)
- 1.1: `Shape`, число осей, размеры и количество элементов (`numel`)
- 1.2: вычисление шагов по форме тензора (`Strides`)
- 1.3: хранилище данных (`Storage`)
- 1.4: первый `Tensor`
- 1.5: конструкторы `zeros`, `ones` и `from_vec` (готово)
- 1.6: индексирование (готово)
- 1.7: изменение формы тензора
- 1.8: поэлементные операции
- 1.9: автоматическое согласование форм для поэлементных операций
- 1.10: суммирование, усреднение и другие операции по осям
- 1.11: умножение матриц
- 1.12: срезы и представления для чтения после базовых операций

## Дальнейшее развитие

- Уровень 2: автоматическое дифференцирование
- Уровень 3: ядро нейронных сетей
- Уровень 4: механизм самовнимания
- Уровень 5: архитектура трансформера
- Уровень 6: небольшая языковая модель GPT
- Уровень 7: данные, средства обучения, оценки моделей и измерения производительности
- Уровень 8: оптимизация вычислений на процессоре
- Уровень 9: вычисления на видеокартах и других ускорителях
- Уровень 10+: общая основа для языковых моделей, компьютерного зрения и совместной работы с разными типами данных

## Дополнительные направления

- Общие интерфейсы операций и подключаемые реализации
- Отдельный необязательный модуль квантования
- Запуск небольшой модели на устройствах с ограниченными ресурсами
- Серверная часть и веб-интерфейс для запуска моделей
- WebAssembly и пакет для JavaScript/TypeScript
